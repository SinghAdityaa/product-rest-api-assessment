# Submission checklist

1. Run `dotnet test` or `docker compose up --build` and confirm no errors.
2. Open Swagger and test `GET /api/v1/products`.
3. Login with the demo admin, click Swagger **Authorize**, and test POST/PUT/DELETE.
4. Capture a screenshot showing Swagger running locally.
5. Create a new public GitHub repository (do not upload to the assessment repository).
6. Push this repository.
7. Email the repository URL plus screenshot with subject exactly: **CRN Technical Assessment Complete Successfully**.
